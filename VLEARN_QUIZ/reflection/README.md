# Reflection

Mỗi thành viên tạo một file riêng theo mẫu `TEMPLATE.md`:

```text
reflection/
├── README.md
├── TEMPLATE.md
├── member-01.md
├── member-02.md
├── member-03.md
├── member-04.md
└── member-05.md
```

Đổi tên file theo mã học viên nếu ban tổ chức yêu cầu. Mỗi người phải giải thích được phần có tên mình theo vibe-coding rule.
